# Jaii Mukundh A — Portfolio

Personal portfolio site for Jaii Mukundh A, focused on ML / LLM engineering, structured extraction, retrieval, and production MLOps.

**Live:** https://jaiimukundh.github.io/

## Stack

Plain HTML, CSS, and JavaScript. No build step, no frameworks. Deployed with GitHub Pages from the `main` branch.

## Structure

- `index.html` — page content
- `styles.css` — layout, theme, responsive styles, motion
- `script.js` — nav, scroll reveal, active links, card spotlight, orb parallax
- `resume.pdf` — current résumé
- `paper.pdf` — accepted AIEI 2027 paper
- `favicon.svg` — site icon

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
