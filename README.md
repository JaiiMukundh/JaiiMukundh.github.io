# Jaii Mukundh A — Portfolio

Personal portfolio site for Jaii Mukundh A, focused on software engineering, ML / AI, structured extraction, retrieval, and production MLOps.

**Live:** https://jaiimukundh.github.io/

## Stack

Plain HTML, CSS, and JavaScript. No build step, no frameworks. Deployed with GitHub Pages from the `main` branch.

## Structure

- `index.html` — page content
- `styles.css` — paper-and-ink visual system, layout, responsive styles, motion
- `script.js` — nav, mobile menu, scroll reveal, active links
- `resume.pdf` — current résumé
- `paper.pdf` — accepted AIEI 2027 paper
- `paper-page.webp` / `paper-page.png` — first-page preview of the paper
- `favicon.svg` — site icon

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
