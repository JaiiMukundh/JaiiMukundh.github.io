03 Selected Work

Systems, not just models.

Featured · AIEI 2027

Structured Event Extraction with Small Language Models

Supply Chain Event Extraction Pipeline · FORMCEPT Internship

GitHub ↗ Paper ↗

A resource-efficient, two-stage pipeline that turns unstructured supply-chain news into schema-valid disruption events. DistilBERT triage filters candidate chunks, a LoRA-adapted Qwen2.5-1.5B model extracts events, and Outlines FSM decoding guarantees structurally valid JSON.

  • 18.46M LoRA adapters (1.2% of the 1.54B base), trained on 115 documents from a 175-document annotated extraction set.
  • Schema-valid JSON 23.33% → 100%; overall extraction F1 46.81% → 69.24%; Top-Level F1 58.40% → 83.97%.
  • DistilBERT triage runs in ~15 ms/chunk vs ~14.32 s for Qwen, routing ~80% of enterprise documents away and cutting Qwen workload ~5×.
